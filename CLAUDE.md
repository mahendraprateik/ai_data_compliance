# AI Data Compliance

This project explores AI-powered analysis of Hacker News data. It has three main components:

1. **Data pipeline** (`setup_data.py`) — Downloads the full Hacker News dataset (~41M posts and comments) from Hugging Face (`OpenPipe/hacker-news`) and loads it into a local SQLite database (`hackernews.db`).

2. **LangGraph agent** (`agent.py`) — A conversational agent built with LangGraph and ChatGPT (`gpt-4o-mini`). Equipped with database, PII detection, and schema monitoring tools. Reads its OpenAI API key from `secrets.txt`.

3. **Ambient PII monitor** (`monitor.py`) — A standalone monitoring loop that uses a LangGraph graph to detect schema changes, scan for PII, and generate audit reports.

## Project structure

- `setup_data.py` — Data download and SQLite ingestion script. Supports `--limit N` for testing with a subset.
- `agent.py` — LangGraph chatbot agent with PII/DB tools bound to the LLM.
- `monitor.py` — Ambient PII monitor entry point. Runs once or loops on an interval.
- `tools/` — LangGraph-compatible tools (`@tool` decorator):
  - `db_tools.py` — Database inspection (list tables, schema, sample data, read-only queries, metadata).
  - `pii_tools.py` — PII detection (scan columns/tables for email, phone, SSN, credit card, IP, DOB patterns).
  - `schema_monitor.py` — Schema change detection (snapshot, compare, detect drift).
- `graphs/pii_monitor.py` — LangGraph `StateGraph` for the ambient monitoring pipeline.
- `schema_snapshots/` — Timestamped JSON schema snapshots (gitignored except `.gitkeep`).
- `secrets.txt` — Holds the OpenAI API key (gitignored). Supports both `sk-...` and `OPENAI_API_KEY=sk-...` formats.
- `hackernews.db` — SQLite database with a `posts` table (gitignored, generated by `setup_data.py`).
- `requirements.txt` — Python dependencies.

## Setup

```bash
pip install -r requirements.txt
```

Add your OpenAI API key to `secrets.txt`:
```
sk-proj-your-key-here
```

## Usage

Load the dataset:
```bash
python setup_data.py            # full dataset (~41M rows)
python setup_data.py --limit 50000  # quick test subset
```

Run the chatbot agent:
```bash
python agent.py
```

Run the ambient PII monitor:
```bash
python monitor.py                        # single run
python monitor.py --full-scan            # full PII scan
python monitor.py --loop                 # every 5 minutes
python monitor.py --loop --interval 60   # every 60 seconds
```

## Configuration

- `HACKERNEWS_DB_PATH` env var — Override the SQLite database path (default: `hackernews.db` in project root).
- `AUDIT_LOG_DB_PATH` env var — Override the audit log database path (defaults to same as `HACKERNEWS_DB_PATH`).

## Dependencies

- `datasets`, `pandas` — for data download and processing
- `langgraph`, `langchain-core`, `langchain-openai` — for the agent and monitoring graph
- `sqlite3` — Python built-in, no install needed
